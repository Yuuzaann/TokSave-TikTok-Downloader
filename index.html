Cara pakai

  1. Salin link Di TikTok, ketuk Bagikan lalu Salin Link.
  2. Tempel Tempel di kolom atas. Link yang ditempel langsung diproses.
  3. Pilih format Video HD, SD, MP3, cover, atau ZIP foto.
  4. Simpan File terunduh dengan nama sesuai judul videonya.

Jika unduhan malah memutar video, tekan lama tombolnya lalu pilih Simpan. Pintasan: tekan / untuk fokus ke kolom link.
